01

Objetivo de la Práctica

Implementar y analizar, en un entorno de laboratorio controlado, una simulación de ingeniería social mediante Social-Engineer Toolkit (SET), utilizando una página web ficticia para comprender el funcionamiento de una técnica de captura de información (Credential Harvester) y reconocer los elementos que permiten identificar un intento de phishing.

02

Desarrollo

Se elaboró una página HTML ficticia que simulaba un portal institucional de autenticación (con logotipo, campos de usuario/contraseña y mensaje de sesión expirada). Posteriormente se configuró Social-Engineer Toolkit en la ruta:

  • Social-Engineering Attacks → Website Attack Vectors → Credential Harvester Attack Method → Custom Import

Se importó el archivo index.html y se levantó el harvester en el puerto 80 utilizando la IP local de la máquina Kali. Al acceder desde el navegador e ingresar credenciales de prueba, SET interceptó la petición POST, extrajo los datos y los registró tanto en pantalla como en archivos locales.

Durante el análisis se identificaron los siguientes indicadores de phishing:

  • Uso de IP o dominio inventado
  • Conexión HTTP (sin cifrado)
  • Ausencia de candado de seguridad
  • Mensaje genérico de “sesión expirada”
  • Atributo action="#" en el formulario

Como controles de seguridad se propusieron: verificación de URL, inspección del tráfico (F12), uso de gestores de contraseñas, exigencia de HTTPS y revisión del código fuente del formulario.

04

Conclusiones

La práctica permitió comprender el funcionamiento del módulo Credential Harvester de SET y el flujo completo de un ataque de phishing por captura de credenciales. Se evidenció que una página con apariencia institucional puede resultar convincente, pero existen indicadores técnicos claros (dominio, protocolo, código del formulario, etc.) que facilitan su detección.

Los controles más efectivos combinan la concientización del usuario con medidas técnicas como gestores de contraseñas, verificación de HTTPS y, especialmente, la autenticación multifactor (MFA). Este tipo de ejercicios deben realizarse únicamente en entornos controlados y con fines educativos.
