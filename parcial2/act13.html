01

Objetivo de la Actividad

Desarrollar un informe técnico profesional de pruebas de penetración (Pentesting Report) sobre la máquina vulnerable My File Server: 1 (VulnHub), aplicando una metodología estructurada de evaluación de seguridad. Posteriormente, elaborar una presentación ejecutiva orientada al Consejo Directivo de una organización.

Rol asumido: Analista Red Team contratado por la organización para evaluar el nivel de exposición del sistema de archivos corporativo.
02

Metodología Aplicada

La evaluación se realizó siguiendo el estándar PTES (Penetration Testing Execution Standard), estructurado en las siguientes fases:

  • Reconocimiento
    Identificación de hosts activos y superficie de ataque del segmento de red.
  • Enumeración
    Análisis de servicios expuestos (FTP, SSH, HTTP, SMB) y obtención de información sensible.
  • Explotación
    Uso de credenciales expuestas e inyección de clave SSH para obtener acceso inicial.
  • Escalada de privilegios
    Explotación de vulnerabilidad local (Dirty COW – CVE-2016-5195) para obtener control total (root).
  • Análisis de impacto y recomendaciones
    Evaluación del impacto bajo el modelo CIA y definición de un plan de remediación prioritizado.
03

Herramientas Utilizadas

Se emplearon herramientas estándar de la industria para cada fase de la evaluación:

netdiscover Descubrimiento de hosts
nmap Escaneo de puertos y servicios
nikto Análisis del servicio web
smbmap / smbclient Enumeración SMB
ftp Acceso y transferencia de archivos
ssh-keygen Generación de claves SSH
gcc Compilación del exploit
Dirty COW Escalada de privilegios
04

Hallazgos Principales

Durante la evaluación se identificaron vulnerabilidades que permitieron el compromiso total del sistema:

ALTA
Credenciales expuestas en texto plano Archivo público en el servicio web contenía la contraseña del usuario del sistema.
ALTA
Acceso anónimo a servicios de archivos FTP y SMB permitían acceso y escritura sin autenticación, exponiendo información sensible.
ALTA
Configuración deficiente de acceso remoto Fue posible inyectar una clave SSH a través de FTP y obtener una sesión remota válida.
CRÍTICA
Vulnerabilidad de escalada de privilegios (Dirty COW) El núcleo del sistema permitía elevar privilegios hasta obtener control total (root).
NIVEL DE RIESGO: CRÍTICO
05

Impacto de Negocio

Un atacante real que explotara estas vulnerabilidades podría:

  • Robar información confidencial almacenada en el servidor de archivos.
  • Modificar o eliminar datos críticos de la organización.
  • Utilizar el servidor como punto de pivote para atacar otros sistemas de la red interna.
  • Afectar la disponibilidad del servicio de archivos, impactando la operación diaria.
Modelo CIA: Confidencialidad → Crítico  |  Integridad → Crítico  |  Disponibilidad → Alto
06

Desarrollo y Resultados

La práctica se realizó sobre la máquina virtual My File Server: 1 (VulnHub), simulando un entorno corporativo de servidor de archivos. Se documentó de forma estructurada cada fase del proceso ofensivo, desde el reconocimiento inicial hasta la obtención de privilegios de administrador.

Como resultado, se elaboraron dos productos profesionales:

  • Informe técnico con estructura ejecutiva y técnica, tabla de hallazgos, análisis de impacto y recomendaciones de remediación.
  • Presentación ejecutiva (10 diapositivas) orientada al Consejo Directivo, con enfoque estratégico, gráficos de riesgo y roadmap de remediación.
07

Conclusiones

Esta actividad permitió aplicar de forma integral una metodología formal de pruebas de penetración, combinar análisis técnico con redacción profesional y comunicar el riesgo en términos de negocio.

Se evidenció que configuraciones deficientes (accesos anónimos, credenciales expuestas y sistemas desactualizados) pueden derivar en el compromiso total de un activo crítico. La capacidad de documentar y presentar estos hallazgos de forma ejecutiva es una competencia esencial en el perfil de un profesional de ciberseguridad.
