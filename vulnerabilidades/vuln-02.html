VULN-02

"Fuga de credenciales mediante archivo de entorno (.env)"

← Volver al proyecto PR02

Descripción técnica y causa raíz

Durante la enumeración del servidor, se identificó que el portal permitía el listado de directorios (Directory Listing) en rutas de configuración. Esto dejó expuesto públicamente el archivo de variables de entorno (.env), revelando credenciales de la base de datos y secretos de la aplicación en texto plano.

Causa raíz: Configuración insegura del servidor web que mantenía activado el listado de índices (Directory Listing). Adicionalmente, el archivo de configuración fue almacenado dentro de la raíz de documentos públicos (document root) sin reglas que restringieran las peticiones HTTP hacia extensiones sensibles.

Comprobación de los hallazgos

  1. Se exploraron los directorios del portal institucional mediante navegación directa.
  2. Se localizó un directorio de configuración con la funcionalidad de listado de índices habilitada.
  3. Se identificó el archivo oculto .env dentro del directorio expuesto.
  4. Se descargó y abrió el archivo, obteniendo las credenciales de conexión de la base de datos de INTERAFAS.

Impacto y riesgo

Nivel Crítico. La fuga de credenciales de infraestructura otorga a un atacante las llaves directas de la base de datos. Esto facilita la exfiltración masiva de Información de Identificación Personal (PII) de los ciudadanos, así como datos financieros y de facturación, comprometiendo por completo la confidencialidad del organismo.

Mitigaciones

  • Deshabilitar globalmente el listado de directorios en el servidor web (ej. Options -Indexes en Apache).
  • Mover todos los archivos de variables de entorno y secretos fuera de la raíz de documentos públicos (fuera de /var/www/html/).
  • Implementar reglas de denegación de acceso para archivos ocultos y extensiones sensibles (como .env, .ini, .bak).
