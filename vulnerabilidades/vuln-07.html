VULN-07

"Inyección SQL (SQLi) y exposición de base de datos"

← Volver al proyecto PR02

Descripción técnica y causa raíz

Se identificó una vulnerabilidad crítica en los formularios de búsqueda y validación de referencias del portal institucional. El sistema permite a un atacante inyectar y ejecutar sentencias SQL arbitrarias directamente en el motor de base de datos a través de la entrada del usuario.

Causa raíz: Prácticas de codificación insegura, específicamente la concatenación directa de cadenas de texto enviadas por el cliente dentro de las consultas SQL del backend, sin realizar sanitización previa ni utilizar consultas parametrizadas (Prepared Statements).

Comprobación de los hallazgos

  1. Se identificó el endpoint de búsqueda o validación de referencias (ej. validar-referencia.php) interactuando con la base de datos.
  2. Se inyectó un payload de prueba lógica (ej. secuencias booleanas o cláusulas UNION) en el campo de entrada.
  3. Se observó un comportamiento anómalo en la respuesta, alterando la lógica original de la consulta.
  4. Se logró extraer información no autorizada, como registros de otros usuarios y estructura interna, confirmando la ejecución del código inyectado.

Impacto y riesgo

Nivel Crítico. Una inyección SQL permite evadir los controles de autenticación y otorga acceso total de lectura, escritura y modificación sobre la base de datos. Esto facilita un volcado masivo (dump) de Información de Identificación Personal (PII) ciudadana, historial de consumos y datos financieros, materializando el peor escenario de filtración para la institución.

Mitigaciones

  • Implementar obligatoriamente Consultas Parametrizadas (Prepared Statements) utilizando librerías seguras como PDO en PHP para interactuar con la base de datos.
  • Prohibir categóricamente la concatenación dinámica de variables de usuario directamente en las sentencias SQL.
  • Aplicar el principio de mínimo privilegio a la cuenta de servicio de la base de datos, restringiendo permisos innecesarios como la ejecución de comandos del sistema operativo o eliminación de tablas estructurales.
