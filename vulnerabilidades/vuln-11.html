VULN-11

"Path Traversal y Descarga Arbitraria de Archivos (LFI)"

← Volver al proyecto PR02

Descripción técnica y causa raíz

El módulo de descarga de documentos de transparencia de INTERAFAS permite a un atacante manipular los parámetros de entrada para escapar del directorio público asignado y leer archivos restringidos del sistema operativo, bitácoras de auditoría y configuraciones internas.

Causa raíz: Carencia de validación y sanitización en las entradas que interactúan directamente con el sistema de archivos (File System). El servidor acepta secuencias de salto de directorio (como ../) sin normalizar la ruta ni verificar si el archivo final se encuentra dentro de un entorno seguro o "sandbox" permitido[cite: 32].

Comprobación de los hallazgos

  1. Se identificó el endpoint responsable de servir documentos (ej. descarga.php?file=reporte.pdf).
  2. Se interceptó la petición y se inyectaron secuencias de navegación de directorios en el parámetro (ej. ../../../../etc/passwd o rutas hacia logs).
  3. Se envió la petición manipulada al servidor.
  4. El servidor omitió la validación y devolvió en texto plano el contenido de archivos críticos de la infraestructura, confirmando la vulnerabilidad de Local File Inclusion (LFI).

Impacto y riesgo

Nivel Crítico. Un Path Traversal o LFI expone la totalidad del sistema de archivos local al atacante. Permite la lectura de bitácoras de auditoría (exponiendo posibles credenciales o sesiones), archivos de configuración con contraseñas de bases de datos, y código fuente del backend, allanando el camino para la toma de control absoluto del servidor.

Mitigaciones

  • No exponer nombres de archivo ni rutas directas a los usuarios; utilizar identificadores indirectos (ej. IDs alfanuméricos mapeados en la base de datos)[cite: 32].
  • Si es estrictamente necesario utilizar nombres de archivo, extraer y conservar únicamente el nombre final utilizando funciones como basename().
  • Implementar una validación estricta de rutas con realpath(), asegurándose de que la ruta final resuelta comience exactamente con el directorio base permitido.
